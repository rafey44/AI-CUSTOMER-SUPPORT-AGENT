# 🤖 AI Customer Support Agent

An AI-powered customer support application built with CrewAI,
Groq, SQLite, RAG, FAISS, Sentence Transformers, and Streamlit.

## Features

- Check customer information
- Check order status
- Get product information
- Search store policies using RAG
- AI-powered customer support responses
- SQLite database
- FAISS vector search
- Streamlit chat interface

## Technologies

- Python
- CrewAI
- Groq
- SQLite
- RAG
- FAISS
- Sentence Transformers
- Streamlit

## Example Questions

- Where is my order ORD1004?
- Can I return my product?
- What is the shipping policy?
- How much does the Smart Watch cost?
- Can you check customer C003?

## Important

The application is designed to answer using
verified store data and knowledge-base information.
